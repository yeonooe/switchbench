SWITCH

Tell a working robot “No, not that.” Can it switch?

SwitchBench는 음성으로 조작되는 로봇이 실행 도중 들어온 새 명령으로 전환하는지, 그리고 무관한 말에는 흔들리지 않는지 측정하는 챌린지입니다.

LIBERO 시뮬레이터에서 로봇의 동작과 모델을 확인해볼 수 있습니다. 첫 기록은 최신 음성·행동 모델 ELLSA를 베이스라인으로 재현한 모델입니다.

GitHub 참가 방법

Why this challenge

Starting point

ELLSA(End-to-end Listen, Look, Speak and Act, ICLR 2026)는 듣고, 보고, 말하고, 행동하는 일을 한 모델에서 동시에 처리합니다. 실행 중 끼어드는 말도 듣습니다.

The gap

논문은 실행 중 끼어들기를 정지(“Hold on”)로만 평가했습니다. 정지한 뒤 명령에 따라 행동을 바꾸는 상황은 구현, 평가 모두 되어 있지 않습니다.

This project

ELLSA를 공개 체크포인트로 재현하고, 실행 중 명령 전환을 측정하는 과제, 학습·평가 데이터, 평가 코드를 만들었습니다.

Task

로봇은 음성 지시 A를 듣고 작업을 시작합니다. 2, 4, 6초 뒤 사용자가 다시 말하며, 무엇을 말했는지에 따라 해야 할 일이 다릅니다.

Switch
dev 30 에피소드

두 번째 발화: 새 지시 B (“와인병을 캐비닛 위에 올려”)
성공: 발화 이후 과제 B 완수

Keep
dev 10 에피소드

두 번째 발화: 작업과 무관한 질문
성공: 원래 과제 A 완수

Plain
dev 10 에피소드

두 번째 발화 없음
성공: 과제 A 완수 (기본 능력 확인)

Input

매 스텝 카메라 이미지 2장(정면, 손목), 로봇 상태, 지금까지 들린 16 kHz 음성. 과제 이름이나 전사문 같은 텍스트는 없고, 앞으로 나올 음성도 들을 수 없습니다.

Output

7차원 로봇 동작. 한 번에 여러 스텝 분량을 내도 됩니다.

Timing

1 스텝 = 0.1초. 두 번째 발화가 끝난 뒤 300스텝(Plain은 지시 후 300스텝) 안에 성공해야 합니다.

Success check

LIBERO 과제 정의(BDDL)의 목표 조건을 매 스텝 확인합니다.

Baseline & method

Baseline B0

ELLSA (zero-shot)

ELLSA 공개 체크포인트를 추가 학습 없이 사용합니다. 모델 호출은 공식 LIBERO 평가와 같습니다(1초 블록마다 동작 10개, 같은 관측 전처리와 음성 특징). 차이는 앞으로 나올 음성을 무음으로 채워 미래 정보를 막은 것 하나입니다. A100 80GB 1장에서 에피소드당 1–4분이 걸립니다.

ELLSA 저장소 베이스라인 코드 재현 노트북

Proposed P2

학습형 음성 의도 판별 + 재시작

B0의 ELLSA는 실행 중 질문에 모두 대답했고 새 지시의 물체 이름도 알아들었지만, 그 지시를 명령으로 처리한 적은 없습니다. P2는 이 판단을 학습합니다. 고정한 Whisper 인코더와 작은 판별기가 음성만으로 명령 여부를 정하고, 명령이면 ELLSA를 그 발화 기준으로 재시작합니다. 판별기는 SwitchBench-train으로만 학습합니다.

B1·P1·P2 코드 판별기 모델
방법실행 중 발화 처리학습
B1모든 발화에 재시작없음
P1 · ablationWhisper 받아쓰기 + 동사 규칙으로 판별없음
P2 · proposed음성 임베딩 + 학습한 판별기SwitchBench-train
P3 · nextELLSA 자체를 중간 상태 전환 시연으로 LoRA 미세조정SwitchBench-train + 시뮬레이터 궤적

From P2
판별기는 dev 전환 명령 30개를 모두 잡아 재시작하며, 질문 10개에서는 잘못 재시작하지 않았습니다. 단 재시작한 ELLSA는 새 과제를 한 번도 완수하지 못했고, 17번은 새 지시만 들었는데도 원래 과제를 끝냈습니다. 같은 과제를 처음 상태에서 시작하면 90% 성공하며, 남은 병목은 ‘명령인지 판단’이 아니라 작업 중간 상태에서 새 지시를 실행하는 능력입니다.

Dataset

SwitchBench v1.0은 LIBERO-Goal 10개 과제로 만들었습니다. 10개 과제가 같은 부엌 장면과 같은 물체 4개를 공유하므로, 어떤 과제를 하던 중이든 다른 과제를 요청할 수 있습니다. 90개 과제 쌍 모두에서 장면이 같고 시작 시점에 목표가 미리 달성되어 있지 않음을 검증했습니다.

Train

SwitchBench-train
1,760 에피소드 · 음성 클립 1,828

용도: 모든 참가자가 같은 데이터로 학습합니다.

  • Switch 960 · Keep 600 · Plain 200, test 과제 쌍 제외
  • 명령: ELLSA 학습 데이터의 지시 녹음 828개 + 합성 표현 변형
  • 비명령: VoiceAssistant-400K 질문 800개 + 합성 맞장구·장면 질문
  • 새로 생성한 초기 상태 400개, 평가셋과 겹치는 녹음 자동 제거
학습 데이터 전처리

Evaluation

dev · test
각 50 에피소드

용도: 순위 산정. dev는 공개되어 개발에 쓰고, test는 비공개로 최종 순위에만 씁니다.

  • dev: Switch 30 · Keep 10 · Plain 10, 초기 상태 0–24
  • test: 같은 구성, 초기 상태 25–49, 다른 과제 쌍과 질문
  • 음성: ELLSA 테스트 데이터의 공식 지시 녹음과 음성 질문 녹음
dev 데이터 평가 데이터 전처리
규칙

학습은 SwitchBench-train과 공개 사전학습 모델(ELLSA, Whisper 등)만 사용합니다. dev는 튜닝에만, test는 최종 평가에 한 번만 씁니다.

음성 선택

합성 음성(Google TTS)을 쓰면 ELLSA가 정상 지시까지 거부했기 때문에(“Action cancelled”), 평가셋은 ELLSA 학습 분포와 같은 공식 녹음을 씁니다. 합성 음성 조건은 강건성 평가용으로 추가할 예정입니다.

Evaluation

Score = (SSR + KSR) / 2

새 명령에 반응하는 능력과 무관한 말을 무시하는 능력을 함께 봅니다. 모든 말에 반응하는 모델은 Keep에서, 말을 무시하는 모델은 Switch에서 점수를 잃습니다.

지표의미순위 반영
SSRSwitch 에피소드 중 새 과제 B를 완수한 비율Score
KSRKeep 에피소드 중 원래 과제 A를 완수한 비율Score
PSRPlain 성공률. 기본 음성 조작 능력동점 시 순위 결정 · 60% 미만이면 ⚠
Stale completion새 명령 이후 원래 과제 A를 끝내버린 비율진단

Evaluator

에피소드마다 장면을 정해진 초기 상태로 세팅하고, 음성을 시간에 맞춰 흘려보내며, 모델을 호출하고, 매 스텝 목표 달성 여부를 기록합니다. 결과는 에피소드당 JSON 한 줄로 저장되고, 중단 후 다시 실행하면 이어서 진행합니다. 모든 비율은 Wilson 95% 신뢰구간과 함께 보고합니다.
